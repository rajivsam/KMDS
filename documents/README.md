# KMDS Documents Package

This directory contains the Google/OKF-compatible documentation package for KMDS.

## Purpose

The `documents` package provides a lightweight data package wrapper for KMDS documentation material, metadata, and publication-ready assets.

## Contents

- `datapackage.json` — Frictionless Data / OKF-compatible package descriptor
- `README.md` — package summary and usage notes

## Usage

- Use this package descriptor to register KMDS documentation in OKF/Frictionless Data workflows.
- Add documentation files or publication assets under this directory and update `datapackage.json` with new resources.

## Notes

- The license reference expects a project-level `LICENSE` file.
- This package is intentionally minimal and meant to support integration with open-data and documentation catalog systems.
